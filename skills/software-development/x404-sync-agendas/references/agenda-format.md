# x404 Agenda Format Reference

Approved format after the 2026-08-19 iteration with Tony.

## Date/time
- Sync: **Wednesday 8pm ET / Thursday 8am SGT** (Thursday 9am SGT during EST).
- Agenda posted on **Monday**.

## File path
`sources/meeting notes/YYYY-MM-DD x404 Humans Found Sync/YYYY-MM-DD x404 Humans Found Sync Proposed Agenda.md`
where `YYYY-MM-DD` is the Thursday SGT date.

## Required sections (exact order)
1. Hermes / KB / Orchestration Recap
2. Buzz Experiment Updates
3. Action Items Needing Updates
4. Async Action Items (no live discussion needed)
5. Open Questions for Live Discussion
6. Pending Decisions
7. Blockers

## Hyperlinks
- Link every item with KB context to the relevant file.
- Markdown: `[ops-guides/filename.md](https://github.com/X404Humans/x404knowledge/blob/main/ops-guides/filename.md)`
- Slack: `<https://github.com/X404Humans/x404knowledge/blob/main/ops-guides/filename.md|ops-guides/filename.md>`
- Plain items only when self-explanatory.

## Slack post rules
- Header: `:calendar: _Proposed Agenda — YYYY-MM-DD x404 Sync_`
- No `[Proposed Agenda]` subject line.
- Real newlines only.
- URL-first `<URL|display>` links with KB path as display.
- Slack message must match the markdown file.

## Pitfalls
- Don’t post next week’s agenda early.
- Don’t use full GitHub URLs as display text.
- Don’t mix async items into live action items.
- Don’t send literal `\n`.
