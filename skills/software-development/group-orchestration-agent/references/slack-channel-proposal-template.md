:x404: *Proposed Slack Channel Additions*

Before adding any channel, please react/comment. I will not create until there is agreement.

| Proposed channel | Purpose | Rationale |
|---|---|---|
| `#meetings` | Agendas, digests, action items, decisions, status | Consolidates all meeting-related output in one place. |
| `#research-radar` | Daily AI infra/model-release brief | Dedicated sub-agent output so it does not drown #general or #meetings. |

Channels I am **not** proposing now:
- `#build-track` — use a dedicated channel per project when a real build starts.
- `#knowledge-wiki` — route wiki updates to the channel matching the content.

Routing rules:
- Meeting/action/decision/status → `#meetings`
- Agent architecture/ops-guides about the orchestration agent → `#orchestration`
- Group alignment/decisions → `#meetings` or `#general`
- Project-specific synthesis → that project’s channel
